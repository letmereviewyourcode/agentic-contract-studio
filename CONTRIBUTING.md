# Contributing to Agent Contract Studio

We welcome contributions to Agent Contract Studio! Since this is a specialized lab project, please keep the following in mind:

## Process
1. **Fork the repository** to your own GitHub account.
2. **Create a feature branch** (`git checkout -b feature/your-feature-name`).
3. **Write tests** for your changes. This repository maintains a high bar for test coverage (unit + Playwright E2E).
4. **Commit your changes** (`git commit -m 'Add some feature'`).
5. **Push to the branch** (`git push origin feature/your-feature-name`).
6. **Open a Pull Request** against the `main` branch.

## Development Setup
Check the `README.md` for local testing instructions. Remember that `PUBLIC_DEMO` should be toggled depending on whether you are working on the deterministic engine or testing the LLM-powered Polish capability.

## Code of Conduct
Please be respectful and constructive in all issues and pull requests discussions.
